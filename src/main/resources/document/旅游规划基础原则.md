# 旅游规划基础原则

## 文档用途

本文档用于旅游规划助手理解通用的旅行规划原则，包括行程安排、路线设计、时间控制、预算分配和用户偏好匹配。

## 一、旅游规划的核心目标

旅游规划的核心目标不是简单罗列景点，而是根据用户的出发地、目的地、出行天数、预算、同行人群和兴趣偏好，生成合理、可执行、体验较好的旅行方案。

一个好的旅游规划应满足以下要求：

1. 路线顺畅，避免频繁折返。
2. 时间安排合理，避免过度紧凑。
3. 景点、美食、休息和交通之间保持平衡。
4. 符合用户预算和体力情况。
5. 能够提供备选方案，应对天气、排队、闭馆等不确定情况。

## 二、规划前需要确认的信息

在正式生成旅游计划前，应尽量确认以下信息：

| 信息类型 | 示例                                     |
| -------- | ---------------------------------------- |
| 出发地   | 上海、北京、南京                         |
| 目的地   | 杭州、成都、厦门                         |
| 出行天数 | 一日游、两天一夜、三天两夜               |
| 出行时间 | 周末、节假日、工作日                     |
| 同行人群 | 独自旅行、情侣、朋友、亲子、老人         |
| 预算范围 | 低预算、中等预算、高预算                 |
| 兴趣偏好 | 美食、拍照、自然风景、历史文化、城市漫步 |
| 交通方式 | 高铁、自驾、飞机、公共交通               |
| 住宿偏好 | 靠近景点、靠近地铁、安静、性价比高       |

如果用户没有提供完整信息，可以先基于已知信息生成初步方案，并标注假设条件。

## 三、行程安排原则

### 1. 每天景点数量不宜过多

一般情况下：

- 一日游适合安排 2 到 4 个核心地点。
- 两天一夜适合安排 4 到 7 个核心地点。
- 三天两夜适合安排 6 到 10 个核心地点。

如果景点之间距离较远，应减少当天景点数量。

### 2. 上午适合安排核心景点

上午体力较好，适合安排：

- 热门景区
- 博物馆
- 自然风景区
- 需要排队的项目
- 需要较长游览时间的地点

### 3. 下午适合安排轻量游览

下午适合安排：

- 城市街区
- 咖啡店
- 商圈
- 拍照点
- 公园
- 文化街区

### 4. 晚上适合安排美食和夜景

晚上适合安排：

- 夜市
- 美食街
- 江景、湖景、城市夜景
- 商业街
- 酒吧街
- 演出活动

## 四、路线设计原则

路线设计应优先考虑空间上的顺路关系。

推荐顺序：

1. 先确定住宿区域。
2. 再确定每天的主要活动区域。
3. 同一天尽量安排相邻区域的景点。
4. 避免上午在城市东边，下午去西边，晚上再回东边。
5. 对跨城旅行，应优先安排交通枢纽附近的景点。

## 五、预算规划原则

预算通常包括：

| 类型     | 内容                   |
| -------- | ---------------------- |
| 大交通   | 飞机、高铁、长途汽车   |
| 市内交通 | 地铁、公交、打车、租车 |
| 住宿     | 酒店、民宿、青旅       |
| 餐饮     | 早餐、正餐、小吃、饮品 |
| 门票     | 景区、博物馆、演出     |
| 购物     | 伴手礼、纪念品         |
| 备用金   | 临时交通、应急消费     |

低预算用户应优先推荐：

- 公共交通
- 免费景点
- 平价餐饮
- 性价比住宿
- 城市漫步路线

高预算用户可以推荐：

- 品质酒店
- 特色餐厅
- 包车或打车
- 付费体验项目
- 私人导览

## 六、不同人群的规划重点

### 情侣旅行

重点关注：

- 拍照氛围
- 浪漫景点
- 咖啡馆、甜品店
- 夜景
- 舒适住宿
- 行程不要过度疲惫

### 亲子旅行

重点关注：

- 安全性
- 路线轻松
- 休息时间
- 儿童友好设施
- 动物园、科技馆、博物馆、主题乐园

### 老人旅行

重点关注：

- 少走路
- 交通方便
- 医疗便利
- 饮食清淡
- 避免高强度爬山和长时间排队

### 朋友旅行

重点关注：

- 美食
- 打卡
- 夜生活
- 体验项目
- 拍照地点
- 行程灵活度

### 独自旅行

重点关注：

- 安全
- 交通便利
- 住宿位置
- 城市漫步
- 博物馆、书店、咖啡馆等适合独处的地点

## 七、输出旅游计划时应包含的内容

一个完整的旅游计划建议包含：

1. 行程概览
2. 每日路线
3. 每个地点的推荐理由
4. 时间安排
5. 交通建议
6. 餐饮建议
7. 预算估算
8. 注意事项
9. 备选方案
10. 适合人群说明

## 八、常见错误

旅游规划中应避免以下问题：

1. 一天安排过多景点。
2. 忽略景点之间距离。
3. 没有预留吃饭和休息时间。
4. 没有考虑景区开放时间。
5. 只推荐热门景点，缺少个性化匹配。
6. 忽略用户预算。
7. 没有提供雨天或人多时的替代方案。
