# 旅游用户偏好分析指南

## 文档用途

本文档用于帮助旅游规划助手根据用户偏好生成个性化旅行方案。

## 一、常见旅游偏好类型

用户的旅游偏好通常可以分为以下类型：

| 偏好类型 | 典型需求                               |
| -------- | -------------------------------------- |
| 美食型   | 想吃当地特色、小吃、夜市、网红餐厅     |
| 拍照型   | 想去出片地点、街区、自然景观、城市地标 |
| 文化型   | 喜欢博物馆、历史街区、古建筑、展览     |
| 自然型   | 喜欢山水、公园、海边、湖泊、徒步       |
| 休闲型   | 不想太累，喜欢咖啡馆、散步、慢节奏     |
| 亲子型   | 适合孩子，有互动体验，安全方便         |
| 穷游型   | 控制预算，公共交通，免费景点           |
| 高品质型 | 注重酒店、餐厅、舒适度和服务体验       |
| 特种兵型 | 想尽量多打卡，行程紧凑                 |
| 避坑型   | 想避开人多、商业化、排队严重的地点     |

## 二、根据偏好调整行程

### 美食型用户

规划重点：

1. 每天至少安排 1 到 2 个特色餐饮点。
2. 晚上可安排夜市、美食街或本地小吃集中区域。
3. 景点之间可以围绕餐饮区域设计。
4. 推荐时说明菜品特色和适合时间段。

不宜：

- 只安排景点，不安排吃饭。
- 把餐厅安排在距离路线很远的位置。
- 推荐过多排队严重的网红店。

### 拍照型用户

规划重点：

1. 优先考虑光线和时间段。
2. 上午和傍晚适合安排户外拍照点。
3. 夜晚适合安排夜景、灯光街区、江边湖边。
4. 推荐地点时说明适合拍摄的角度或氛围。

适合地点：

- 城市地标
- 老街区
- 海边
- 湖边
- 公园
- 艺术园区
- 咖啡馆
- 特色建筑

### 文化型用户

规划重点：

1. 安排博物馆、历史建筑、文化街区。
2. 注意闭馆时间。
3. 每个文化景点应预留较长参观时间。
4. 可以加入简要背景介绍。

适合地点：

- 博物馆
- 美术馆
- 古镇
- 历史街区
- 名人故居
- 寺庙
- 展览馆

### 自然型用户

规划重点：

1. 关注天气。
2. 关注体力消耗。
3. 山地、徒步路线应说明难度。
4. 给出雨天备选方案。

适合地点：

- 山
- 湖
- 海边
- 森林公园
- 湿地
- 草原
- 河岸步道

### 休闲型用户

规划重点：

1. 景点数量减少。
2. 增加咖啡馆、书店、公园、散步路线。
3. 每天安排充足休息时间。
4. 避免早起和长距离通勤。

适合输出风格：

- 慢节奏
- 舒适
- 不赶路
- 适合放松
- 体验城市氛围

### 特种兵型用户

规划重点：

1. 行程可以紧凑，但要保证交通可行。
2. 每个地点停留时间较短。
3. 应明确提醒体力消耗较大。
4. 尽量选择公共交通或打车效率高的路线。

注意：

特种兵路线不适合老人、亲子、低体力用户。

## 三、根据同行人群调整方案

### 情侣

推荐内容：

- 浪漫夜景
- 拍照点
- 咖啡馆
- 湖边、江边、海边
- 有氛围感的餐厅
- 舒适住宿

### 朋友

推荐内容：

- 美食街
- 商圈
- 拍照点
- 夜生活
- 娱乐项目
- 适合多人互动的体验

### 亲子

推荐内容：

- 动物园
- 科技馆
- 博物馆
- 海洋馆
- 主题乐园
- 公园
- 儿童友好餐厅

### 老人

推荐内容：

- 低强度路线
- 有座椅和休息区的景点
- 交通便利区域
- 饮食清淡
- 医疗资源较近区域

## 四、用户表达与偏好识别

| 用户表达       | 可推断偏好         |
| -------------- | ------------------ |
| 想吃好吃的     | 美食型             |
| 想拍照出片     | 拍照型             |
| 不想太累       | 休闲型             |
| 想多玩几个地方 | 特种兵型           |
| 带孩子         | 亲子型             |
| 带爸妈         | 低强度、舒适型     |
| 预算有限       | 穷游型             |
| 想住好一点     | 高品质型           |
| 不想踩雷       | 避坑型             |
| 想体验当地生活 | 深度游、城市漫步型 |

## 五、偏好冲突处理

如果用户同时提出多个偏好，需要进行平衡。

示例：

用户既想“多打卡”，又说“不想太累”，应优先保证舒适度，安排核心景点，不做极限打卡。

用户既想“预算低”，又想“住好吃好”，应优先说明预算限制，并推荐性价比方案。

用户既想“亲子”，又想“夜生活”，应优先考虑孩子作息和安全，夜间活动适当减少。
