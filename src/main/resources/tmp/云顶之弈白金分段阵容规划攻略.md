## 1. 白金分段核心思路

### 🎯 上分三大原则

| 原则 | 说明 |
|------|------|
| **专精2-3套阵容** | 别贪多，白金分段专精几套热门阵容就够了 |
| **经济运营为王** | 学会存50金币吃利息，不要每回合D牌 |
| **灵活变阵** | 根据发牌员给的牌和装备，灵活选择阵容 |

### 💰 经济运营基础
- **2-1阶段**：不花钱升人口，看发牌
- **3-2阶段**：升6人口，开始凑羁绊
- **4-1阶段**：升7人口，搜关键4费卡
- **4-5~5-1阶段**：升8人口，找核心大哥

```
💡 核心口诀：
不想掉分先存钱，50利息是根本
不追三星不乱D，血量健康才上分
```

## 5. 运营节奏与升人口策略

### 📊 标准运营节奏表

| 阶段 | 人口 | 金币策略 | 操作要点 |
|:----:|:----:|:--------:|:--------:|
| 2-1 | 4 | 不花钱 | 拿强势卡/凑小羁绊 |
| 2-5 | 5 | 存钱到50+ | 利用利息升级 |
| 3-2 | 6 | 可花10-20块 | 搜2星前排/关键羁绊 |
| 3-5 | 6~7 | 继续存钱 | 白嫖为主 |
| 4-1 | 7 | 花20-30块 | 找4费核心卡 |
| 4-5 | 7~8 | 大搜 | 提升质量 |
| 5-1 | 8 | 搜到30块 | 找齐阵容2星 |
| 6-1+ | 9 | 看情况 | 追3星/上9补强 |

### 💡 特定情况运营

**连胜开局**：
```
2-1 升4人口（如果可能）
2-3 升5人口保连胜
3-1 升6人口继续保连胜
利用连胜经济快速上8
```

**连败开局**：
```
不升人口，保持低质量
吃满连败利息（最大+3额外金币）
3-2 升6人口逆转
4-1 升7人口大搜
```

## 7. 新手常见错误与改进

### ❌ 常见错误

| 错误 ❌ | 正确做法 ✅ |
|:-------:|:----------:|
| 每回合D牌直到没钱 | 存50金币，只花利息钱 |
| 装备随意给 | 提前确定主C，围绕核心做装 |
| 什么牌都拿 | 确定2-3套阵容，其他牌果断卖 |
| 盲目追3星 | 除非1费/2费核心，否则2星就停 |
| 不考虑站位 | 坦克放前排，C位放角落防刺客 |

### 🏆 白金分段上分小技巧

1. **开局观察** - 前三个装备掉落后，基本决定了你这局能玩什么阵容
2. **灵活切换** - 如果某阵容被很多人抢，果断切换备选阵容
3. **血量管理** - 血量也是一种资源，60血以上可以贪经济
4. **魔装机神/选秀** - 选秀时优先拿自己缺的核心装备
5. **学习复盘** - 每局结束后回顾自己哪里可以做得更好

```
🌟 白金上分最终秘诀：
不是玩得有多花哨，而是把基本功做扎实！
经济、装备、站位、血量管理，做好这四点轻松上分！
```
